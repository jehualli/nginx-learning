3. Concepts at work here

  • Reverse proxy — nginx sits in front, forwards /api/* to Node
  • Load balancing — round-robin across backend1 & backend2
  • Static serving — this page is served by nginx with zero app code
  • TLS termination — HTTPS ends here; backends speak plain HTTP internally
